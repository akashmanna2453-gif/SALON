# ✨ Salon — Premium Salon Website Demo

A modern, elegant and fully responsive **salon website demo** designed for local beauty and salon businesses.

The website focuses on creating a premium visual experience while making it easy for customers to explore services and book appointments directly through WhatsApp.

> **This is a demo project. All salon information, pricing, reviews, images and contact details currently used on the website are placeholder/demo content.**

## 🛠️ Built With

This project is intentionally built using only lightweight frontend technologies.

- **HTML5** — Website structure
- **CSS3** — Styling, animations and responsive design
- **Vanilla JavaScript** — Interactions and functionality

### 🚫 No Frameworks

This project does **not** use:

- React
- Vue
- Angular
- Bootstrap
- Tailwind CSS
- jQuery
- Next.js
- Backend
- Database
- Authentication

The website can run directly in a browser without any build process.
