# Luxe Studio Salon Website

A premium, luxury salon landing page built with plain HTML, CSS, and vanilla JavaScript.

## Overview
This project is a modern salon website designed to feel premium, polished, and conversion-focused for WhatsApp appointment bookings. It is built to work by simply opening `index.html` in a browser without any backend or framework.

## Features
- Sticky premium navbar with mobile menu
- Full-screen cinematic hero section
- Statistics counters with scroll animation
- Premium service cards with WhatsApp booking
- About section and luxury brand storytelling
- Promotional offer banner
- Responsive gallery with hover overlays
- Why choose us feature blocks
- Testimonial carousel
- Instagram section
- CTA for WhatsApp and call booking
- Contact form with client-side validation
- Google Maps embed area
- Footer with quick links and contact information
- Accessibility and responsive mobile-first layout

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Open the project folder.
2. Double-click `index.html` in a browser, or open it with any browser directly.
3. The website works without installing dependencies or running a server.

## WhatsApp Booking
The website uses a shared configuration object in `script.js` to manage the salon details and WhatsApp number. All booking actions open WhatsApp with a pre-filled appointment message.

## Customization
Update the values in `script.js` to match your business:
- salon name
- phone number
- WhatsApp number
- address
- Instagram URL
- Google Maps URL

## Notes
This is a static marketing website intended for beauty and salon businesses that want to convert visitors into appointment bookings through WhatsApp.
